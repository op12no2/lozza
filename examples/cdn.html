CDN

Lozza can be loaded straight from GitHub via the jsDelivr CDN, with no need to download lozza.js. Browsers will not start a Web Worker from another origin with new Worker(url), so instead a tiny worker is created from a Blob, which pulls Lozza in with importScripts (allowed cross-origin). After that it's used exactly like a local new Worker('lozza.js').

The URL is https://cdn.jsdelivr.net/gh/op12no2/lozza@<version>/examples/lozza.js, where <version> is a release tag or main. Only releases from 11.0 onwards can be targeted like this; earlier releases do not have a standalone examples/lozza.js in their tags.

Release 11.0

A release tag always serves the same file, so this is what to use in your own pages.




Main



The main branch serves the current development build, which may be newer than the latest release. jsDelivr caches branch URLs for up to 12 hours, so it can lag behind the repo a little.
