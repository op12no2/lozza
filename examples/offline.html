Offline

Lozza needs no server once it's loaded, since the net is embedded in lozza.js, so a page using it can work with no connection at all. This page registers a service worker (offline-sw.js) that caches the page and lozza.js on the first visit. Later visits are served from the cache, while a fresh copy is fetched in the background for next time, so a new lozza.js is picked up on the visit after it's published. To try it, load this page once, go offline (airplane mode, or DevTools > Network > Offline) and reload. Service workers need https or localhost.
